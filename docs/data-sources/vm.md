# orchard_vm (Data Source)

Retrieves information about a specific VM or a list of VMs. If `name` is omitted, returns all VMs (optionally filtered).

## Example Usage

```terraform
provider "orchard" {
  token    = "your-service-account-token"
  base_url = "http://localhost:8080"
}

# A single VM
data "orchard_vm" "dev" {
  name = "dev-box"
}

# All VMs on a specific worker
data "orchard_vm" "on_worker1" {
  filter = "worker=worker1"
}
```
